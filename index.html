02 · ML Project · 개인 프로젝트

SMS 스팸 문자 분류 프로젝트

5,572건의 영문 SMS 데이터를 활용해 TF-IDF 기반 전통 ML 3종과 BERT 파인튜닝을 비교하고, SHAP으로 모델 해석성까지 확보한 텍스트 분류 파이프라인 학습 프로젝트입니다.

Python Scikit-learn TF-IDF BERT Hugging Face SHAP Pandas
📓 분석 파이프라인 (개인 프로젝트)
01
데이터 전처리
SMS Spam Collection 데이터셋(5,572건) 정제 · 라벨 인코딩 · Train/Test 분리 · 클래스 분포 확인
02
베이스라인 모델 비교
TF-IDF 벡터화 후 Logistic Regression · Random Forest · XGBoost 3종 학습 및 성능 비교
03
BERT 파인튜닝
Hugging Face Transformers 기반 사전학습 BERT 파인튜닝 · Tokenizer 적용 · GPU(T4) 학습 환경 구성
04
SHAP 해석성 분석
스팸 판단에 영향을 미치는 핵심 단어 패턴 시각화 · 모델 결과를 설명 가능하게 변환
📊 모델 성능 비교
Logistic Regression 97.13%
Random Forest 97.49%
XGBoost 97.22%
BERT (Fine-tuned) 98.92% ✓
🔍 무엇을 발견했는가
  • 단순 모델(LR 97.13% · RF 97.49% · XGBoost 97.22%)로도 깨끗한 영문 데이터셋에서 97%대 분류 가능
  • BERT 파인튜닝은 베이스라인 대비 1~2%p 개선에 그침 → 모델 선택은 정확도만이 아니라 데이터 특성과 추론 비용을 함께 고려해야 함을 직접 확인
  • SHAP 분석에서 "free", "win", "claim" 등 광고·당첨 관련 키워드가 스팸 판단의 핵심 신호로 작용함을 확인
💡 인사이트 & 확장 방향
  • 한국어 피싱 문자처럼 노이즈·신조어가 많은 실제 도메인으로 확장 시 OOV 토큰 처리, 클래스 불균형 보정, 도메인 특화 사전 구축이 핵심 과제 → 관련 기법 추가 학습 중
